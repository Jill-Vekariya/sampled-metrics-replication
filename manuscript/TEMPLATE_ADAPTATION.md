# Template and build choice

Verified ReScience template commit: 0978d0e5d9a86246789fd3468aec6fc71e39c944, https://github.com/ReScience/template.

Its README makes LaTeX optional, YAML metadata mandatory, and permits another build system with the proposed PDF style. The local TeX installation lacks the template's packages and bibliography backend. The manuscript therefore uses an original ReportLab layout with serif body text, sans-serif headings, red accent, numbered figures/tables and A4 pages. Metadata follows the current supplied YAML structure.

The header explicitly says PRE-SUBMISSION DRAFT. The template's default UNDER REVIEW banner, sample author names, sample publication dates and default no-conflict assertion were not carried into the manuscript. No editorial decisions or declarations are invented.

The human-readable manuscript source is article.md; executable source is ../build_manuscript.py. The figures are generated by ../plot_results.py.
